# 2027년 공고 워치리스트

페이퍼닥과 맞지만 **2026년 회차가 이미 끝난** 공고들. 다음 회차를 놓치지 않으려고 남긴다.

## 왜 캘린더가 아니라 이 문서인가

2027년 일정은 **아직 아무도 공고하지 않았다.** 날짜 없이는 D1에 넣을 수 없고, "작년이 4월이었으니 올해도 4월"을 날짜 칸에 적는 순간 그건 가짜 데이터가 된다. 예전에 예창패·GovTech 날짜를 그렇게 추정해서 실제와 어긋난 적이 있다.

그래서 여기엔 **2026년 실제 회차의 출처 URL만** 적는다. 2027년 공고가 뜨면 그때 원문을 확인하고 `/공고추가`로 등록한다.

- **2026년 12월 ~ 2027년 1월** — 중기부 「2027년 창업지원사업 통합공고」. 예창패·초창패 일정이 여기서 확정된다.

## 등록할 때 지킬 것

공고를 캘린더에 넣을 땐 **공고 원문 페이지에서 마감일시를 직접 확인**한다. 검색 스니펫에 뜨는 날짜는 작년 회차인 경우가 흔하다. 마감 시각을 못 찾으면 비워두고 `⚠️ 마감 시각 미확인`으로 두지, 추정해서 채우지 않는다.
