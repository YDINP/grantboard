## 1. 해외 클라우드·AI 크레딧

### 1-0. 먼저, 전제가 틀렸던 부분

이 아이템의 변동비는 이미지 OCR 호출비와 LLM 구조화 추출 호출비다. 그래서 크레딧을 현금
대체재로 봤는데, **주요 프로그램이 바로 그 비용을 못 덮는다.**

| 프로그램 | 왜 못 덮는가 |
|---|---|
| Google for Startups | 크레딧이 구글 1P 제품만 커버. 공식 각주: *"Third-party models are billed directly and are not covered by the program credits."* → **Vertex AI의 Claude는 크레딧 결제 불가.** Gemini·Cloud Vision·Document AI는 커버 |
| Anthropic Claude Startups | **현재 신규 접수 중단** (*"Our current cohort is now full, and we're not accepting new applications right now."*). 재개 일정 미공개 |
| OpenAI 스타트업 프로그램 | **VC 추천코드 필수, self-serve 불가.** 비투자 팀에 제공되는 건 Build Hours·쿡북·이벤트뿐, 크레딧 없음 |
| 국내 바우처 전부 | 등록된 공급기업 상품을 구매하는 구조. Anthropic/OpenAI API나 해외 OCR 직접 결제 불가 |
| OCR·비전 전용 크레딧 | **존재하지 않는다.** Mistral `/startups` 404, NVIDIA Inception은 incorporated 필수, Upstage 미확인. Google Cloud Vision 상시 무료 1,000 units/month만 확인 |

> **널리 퍼진 오정보 하나:** Anthropic 스타트업 프로그램의 "$45,000"은 Anthropic API 크레딧이
> 아니라 **파트너사 혜택 묶음(Claude Startup Stack)**이다. 공식 문구는
> *"discounts and credits worth up to $45,000 from companies building with Claude"*.
> API 크레딧 $100K는 **VC 경유만** 가능하고(*"claimed through your VC"*), 파트너 VC 명단은
> 비공개다. 2차 블로그 다수가 이를 API 크레딧으로 소개하는데 공식 문서와 어긋난다.
> 또한 *"Startup credits apply only to the first-party Claude API through Claude Console,
> not AWS, Google Cloud, or Azure."*

즉 크레딧으로 호출비를 덮으려면 **Gemini·Document AI로 갈아타는 경우뿐**이고, 그건 크레딧
문제가 아니라 아키텍처 선택이다. 현재 파이프라인(`lib/ai/mdbox.ts` 경유 Vision + 구조화 추출)을
바꾸는 결정이므로 자금 조달과 분리해서 판단할 것.

## 2. 국내 바우처·비현금 지원

### 2-0. 구조적 제약

**국내 AI·데이터·클라우드 바우처는 전부 「등록된 공급기업의 상품을 구매」하는 방식이다.**
현금을 받아 API 비용을 직접 결제하는 구조가 아니다.

- AI 바우처: 수요기업 단독 신청 불가, NIPA 공급기업 POOL(1,428개사)과 컨소시엄 필수
- 데이터바우처: *"데이터바우처 포털에 등록된 데이터 상품 및 활용 서비스에 한해서만 신청 가능"*
- 클라우드 바우처: 등록된 클라우드 서비스 Pool 한정

쓸 수 있는 것은 **국내 공급기업을 통한 학습데이터 구축·가공, 국내 클라우드 사용료**다.

2026년부터 3개 부처 AX 통합공고 체계로 묶였다 — AI바우처+데이터바우처+클라우드바우처가
한 우산 아래 들어가고(총 718억), 세 사업 공고번호가 모두 과기정통부 제2026-0242호다.
통합공고 개시 2026-03-19. 출처: [3개 부처 보도자료 PDF(2026-03-12 배포)](https://www.motir.go.kr/attach/down/095a2dda9c864e1d90d751f7668a1117/91934d09c6394f3ea0f5567abc08a0ad)

**2027년도 공고는 전부 미공고다.** NIPA 사업공고 게시판 최신글 2026-10-30,
데이터바우처 포털 공지 최신글 2026-11-05 기준.

또한 기업마당에서 현재 접수 중인 "바우처" 13건을 전수 확인한 결과 **물류·수출·에너지·
소상공인·인증뿐이고 AI·데이터·클라우드는 0건**이다.

### 2-1. 데이터바우처 — 사업자등록 없이 되는 국내 유일 바우처

- 과기정통부 공고 제2026-0242호 「2026년 데이터바우처 지원사업 수요기업 모집 공고」
- [기업마당 공식](https://www.bizinfo.go.kr/sii/siia/selectSIIA200Detail.do?pblancId=PBLN_000000000119210) ·
  [포털](https://kdata.or.kr/datavoucher/index.do) · 접수 [PMS](https://kdata.or.kr/pms/)
- 수행 한국데이터산업진흥원(K-DATA), 고객센터 1833-2246

**사업자등록 필수 아님.** 공고문 지원대상에 `중소기업, 소상공인, 예비창업자, 공공·연구기관,
대학연구팀 등`으로 예비창업자가 명시돼 있다. 공모안내서에서 확인한 구체 조항:

- PMS 가입: `(개인회원) 예비창업자, 대학연구팀(대표 교수 개인명의 인증서를 통해 가입)`
- 제출서류: 예비창업자는 **사업자등록증명·법인등기부등본·중소기업확인서 제출 대상 아님.**
  대신 `사실증명(예비창업자)` + `주민등록표(초본) 사본` + 국세·지방세 납세증명서
- 지역 판정: `예비창업자는 주민등록표(초본)상 현주소를 기준으로 함`
- 사후 의무: `수요기업으로 참여하는 예비창업자는 … 협약 종료일까지 사업자 등록 완료 및
  제출 필수` / `사업자 등록을 미이행한 예비창업자의 경우 제재 조치`

→ **신청 시점에 사업자등록이 없어야 유리하고, 협약 종료일까지 등록하면 된다.**

- 멈춘 대상은 법무부 AI리걸테크 특별분과위원회가 만들던 **가이드라인 초안**이다.
  유권해석도 법령도 아니다.
- 초안의 쟁점 조항은 제2조 `변호사는 이 서비스를 일반 소비자에게 유료로 제공할 수 없다`,
  제10조(판단형 AI 이용자를 사내변호사 관리·감독 하 업무 수행자로 한정), 제11조(제공자의
  이용자 자격 확인 의무)다. 해외 범용 AI가 사실상 적용 제외라 국내 기업만 규제된다는
  역차별 지적이 백지화 배경으로 보도됐다.
- **비변호사 사업자의 법률문서 분석 서비스에 대한 영향은 어느 보도에도 언급이 없다 → 미확인.**
  초안이 영향 대상으로 거론한 것은 「법무사·노무사·행정사 등 비변호사 전문직이나 공공기관
  종사자」였다. **초안이 멈춘 것이 비변호사 사업자 규제를 완화했다는 근거는 없고**, 변호사법의
  기존 금지(비변호사의 유상 법률사무 취급)는 그대로다. 변호사법 제109조를 조문 번호로 언급한
  보도도 확인되지 않았다.
- 법무부 공식 입장문은 미확인. 2026-10-16 해설 세미나에서 "통상적인 법무팀 업무 수준이면
  위반으로 보기 어렵다"는 설명이 나왔다는 보도만 있다.

## 4. 신청 순서가 금액을 좌우한다

조사에서 가장 실질적인 발견이다. **사업자등록은 양날의 검이다.**

- 등록하면 열리는 것: 클라우드 바우처(6,910만), AI 바우처(2억), Cloudflare $10k, 융자·보증
- 등록하면 **닫히는 것**: 데이터바우처 민간부담금 면제, 예비창업패키지,
  모두의 창업(예비창업 트랙), 데이터바우처 청년 가점

그런데 데이터바우처는 **신청 시점에 미등록이면 되고 협약 종료일까지 등록하면 된다.**
서울 AI 허브도 **선정 후 30일 내** 설립이면 된다. 즉 순서를 이렇게 잡으면 양쪽을 다 가진다.

```
1단계 (지금 ~ 2027-01)   사업자등록 없이
    · Microsoft for Startups $200          — 지금 가능. 법인·도메인 불필요
                                             (개인 LinkedIn 인증을 먼저 끝낼 것)
    · AWS Activate Founders $1k~5k         — 도메인 불필요. 공식 요건에 없다
    · AI 허브(aihub.or.kr) 무료 데이터로 평가셋·룰셋 보강
    · 2026-12: 모두의 창업 2027년 통합공고 모니터링

2단계 (2027-02 말 ~ 03 말)  여전히 미등록 상태로 신청
    · 데이터바우처 (일반 4,500만 / 공개·활용 7,500만,
      부담금 면제, 청년 가점)                             ← 미등록이어야 면제
    · 모두의 창업 프로젝트 (최대 5억, 로컬트랙은 예비창업 전용)
    · 상금형: 부동산서비스산업(개최 여부 불확실), 소비자지향성, 공공데이터·AI
    · (자금 아님) 서울 AI 허브 1차 입주 — 유료 입주, 선정 후 30일 내 설립

3단계 (선정 후)  사업자등록
    · Cloudflare $10k (법인 필수. 단 자격 문면 모순 → 사전 문의)
    · Microsoft 다음 단계 (registered legal entity 확인)
    · 다음 해 클라우드 바우처 / AI 바우처
```

**국내 경로의 집중 구간은 2월 말~3월 말이다.** 그 전에 끝내야 할 선행 작업:

1. **사업자등록 시점 결정.** 위 순서대로면 2027년 3월 선정 결과가 나온 뒤가 맞다.
   먼저 등록하면 데이터바우처 면제·가점과 모두의 창업 로컬트랙(예비창업자 전용)을
   동시에 잃는다.
2. **도메인은 「먼저 해야 하는 일」이 아니다**(초판 정정). AWS 공식 자격요건에 도메인·웹사이트가
   없다. 도메인이 실제로 걸리는 것은 **Google Start $2,000**(활성 웹사이트 + 도메인 일치 메일)과
   **Cloudflare**(`Has a valid, publicly accessible website`)뿐이다. 둘 다 금액이 작거나
   법인이 전제이므로 **급하지 않다.** 다만 Google은 `We screen for sites that are AI generated`
   로 AI 생성 사이트를 거절하므로, 신청용으로 랜딩을 급조하면 역효과다.
3. **Microsoft는 LinkedIn이 선행이다.** 개인 LinkedIn 프로필 인증을 Azure 계정 생성
   **전에** 끝내야 한다. 이게 안 되면 $200부터 막힌다.

## 조사 방법과 한계

세 갈래 병렬 조사(해외 크레딧 / 국내 바우처 / 상금형 공모전)로 수집했고, 각 조사자에게
**출처 URL 없는 날짜·금액은 보고하지 말 것**을 지시했다. 그래서 이 문서의 「미확인」은
빈칸이 아니라 조사 결과다.

**같은 날 2차로 재검증했다.** 초판의 개별 주장을 네 갈래(해외 크레딧 / 국내 바우처 /
상금형 공모전 / 미해결 쟁점)로 다시 돌려 공식 페이지·공고 원문과 대조했고, 뒤집힌 항목은
§0-1에 모아 뒀다. 2차 검증에서 가장 크게 바뀐 것은 **AWS Activate의 도메인 요건이
공식 자격요건에 없다**는 점이고, 이 때문에 초판의 「도메인 먼저 구입」 권고를 철회했다.
결과는 Discord `#자금조달` 채널에 6개 섹션으로 게시했다.

주요 한계:
- 공고문 첨부파일(HWP·이미지 표)을 열지 못해 미확인으로 남은 항목이 여럿이다
  (AI 바우처 민간매칭 비율, 서울 AI 허브 GPU 혜택 규모, 소비자지향성 상금, 첨단 GPU 본사업 이용료)
- 예비창업패키지 일정은 k-startup 원문이 아니라 2차 자료(벤처스퀘어 공고 미러) 기준이다
- 2027년도 공고는 전부 미공고이므로 모든 예상 접수월은 **예년 회차 기준 추정**이다.
  근거 회차 수를 표에 함께 적었다(1건뿐인 항목은 패턴이라 보기 어렵다)
