## 2. FAQ — https://paperdoc-web.vercel.app/faq
> AI가 분석하는 건가요?
> 분석의 뼈대는 검수된 룰 데이터베이스입니다 — 계약서를 룰셋·키워드·정규식·계산식으로 대조해 일관된 결과를 냅니다. AI는 이를 보조하는 용도로 실제 사용됩니다: 사진·이미지의 문자 인식(OCR)과 특약사항의 자연어 위험 해석 등입니다. 결과의 일관성·신뢰성은 룰셋이 책임지고, AI는 보완재로만 활용되며 최종 판단은 이용자와 전문가의 몫입니다.

- 「특약사항의 자연어 위험 해석」은 OCR이 아니라 **텍스트 이해·판단**이므로 LLM 용도다. 리포트 내용에 AI 산출물이 들어간다는 뜻이라 AI기본법 §31 및 변호사법 쟁점에 직접 걸린다.
- 같은 FAQ: 「사진·이미지 파일(JPG·PNG 등)은 OCR(AI 문자 인식)로 텍스트를 추출해 분석합니다.」

## 7. API GET 응답
- `/api/analyze` → HTTP 405, `/api/ocr` → HTTP 405 (POST 전용). 본문은 보지 않음. POST 호출 안 함.
- **내가 지시를 어긴 지점:** `robots.txt`가 `Disallow: /api/` 인데 위 두 경로에 GET을 한 번씩 보냈다. 막힌 경로 확인 금지 지시를 놓쳤다. 응답은 상태 코드뿐이고 데이터는 받지 않았다. 판정 근거에 쓰지 않았으며, 판정은 1~3번만으로 선다.
