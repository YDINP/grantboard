## Q1. Anthropic Startup Program — 법인 등록·투자 유치 요건이 있는가? 예비창업 팀이 신청 가능한가?

### Takeaway

공식 약관(Official Terms) 원문의 Eligibility 조항에는 **법인 등록·사업자등록·투자 유치 요건이 전혀 없다** — 제재국가/수출통제/임직원 가족 배제만 있다. 다만 신청 자격은 "창업 5년 이내 또는 2년 이내 투자 유치"이고 신청 주체는 "the Company"(회사)를 전제로 하므로 법인 없는 팀의 가능 여부는 **원문으로 확정되지 않는다**. 그리고 결정적으로 **2026-10-13 자로 신청이 마감(cohort full)되어 현재 신청 자체가 불가**하다.

### Cited Findings

**프로그램명:** Claude Startups (Claude for Startups / Anthropic Startup Program)
**운영 주체:** Anthropic
**마감:** **현재 접수 중단.** 공식 프로그램 페이지에 "Our current cohort is now full, and we're not accepting new applications right now." 공식 공지 기사에도 **2026-10-13 업데이트**로 코호트 마감이 반영됨. 약관상 선발 방식은 상시(rolling)였음 — "will select applicants on a rolling basis."

### 상충하는 정보 (주의)

### Inferences

- 약관에 법인 요건이 **없고** 투자도 요건이 아닌 점, "bootstrapped" 기업도 신청 대상으로 거론된 점을 보면 Anthropic 측 설계 의도는 법인 유무를 엄격히 따지지 않는 쪽으로 **보인다**. 그러나 "the Company"를 구속할 권한을 요구하는 조항과 "founded" 의 정의 미비 때문에, 실제 심사에서 사업자등록증·회사 도메인 이메일을 요구할 여지가 남아 있다. **추정이며 확인된 사실이 아니다.**
- 접수 마감 시점(2026-10-13)이 프로그램 확대 발표(2026-10-06) 후 **불과 1주일**이다. 차기 코호트가 열리면 다시 빠르게 마감될 가능성이 높아, 뉴스레터 구독 후 **개설 즉시 신청**하는 준비(제품 설명, 회사 도메인 이메일, Claude Console 계정)가 필요하다는 판단.

### Gaps

- "founded in the last five years" 의 **"founded" 정의**(법인 설립일 기준인지, 팀 결성 기준인지) — 공식 원문에 정의 없음.
- 신청 폼의 실제 입력 필드(사업자등록번호·회사 도메인 이메일 요구 여부) — https://platform.claude.com/offers/startups-application 을 열었으나 **쿠키 동의 배너만 반환**되어 폼 내용을 확인하지 못했다. 현재 접수 마감 상태라 폼 자체가 비활성일 가능성도 있다.
- 차기 코호트 개설 시점 — 공식 페이지에 일정 없음("subscribe to the newsletter to learn when applications open for the next cohort").
- 크레딧 만료 기간 — 공식 원문에서 확인 못 함.

## Q2. OpenAI for Startups — 자격요건과 신청 방법 (선행 조사의 403 해소 시도)

### Takeaway

**해소 실패 — OpenAI 소유 페이지를 끝내 열지 못했다.** openai.com/startups/ 는 **HTTP 403**, help.openai.com 도 **403**, web.archive.org 는 **이 환경에서 차단**되어 아카이브 경로도 막혔다. 대체 경로로 OpenAI 커뮤니티 공식 포럼의 Grove 공고문 1건만 원문 확인했고, 그것은 **크레딧 프로그램이 아니며 2026-01-12 로 이미 마감**됐다. 서드파티 다수가 "OpenAI 자체 스타트업 크레딧 프로그램은 중단됨"이라고 보고하나, **OpenAI 원문으로 교차 검증하지 못했다.**

### Cited Findings

**프로그램명:** OpenAI for Startups (자체 스타트업 크레딧) / OpenAI Grove (별개 프로그램)
**운영 주체:** OpenAI
**마감:**
- 자체 크레딧 프로그램: **미확인** (프로그램의 현존 여부 자체가 미확인)
- OpenAI Grove: **2026-01-12 마감 — 종료됨.** 2026-10-15 기준 열린 회차 없음(확인된 범위 내).
**출처 URL:**
- https://openai.com/startups/ → **HTTP 403 Forbidden** (직접 시도, 본문 미취득)
- https://help.openai.com/en/articles/6950777-what-is-the-openai-startup-program → **HTTP 403 Forbidden** (직접 시도)
- https://web.archive.org/... → **이 환경에서 fetch 차단** (아카이브 우회 불가)
- https://grove.openai.com/ → **DNS 미등록(ENOTFOUND)**
- https://community.openai.com/t/apply-to-openai-grove-for-early-stage-company-builders/1370781 **[직접 열람]** — OpenAI 공식 커뮤니티 포럼 공고, 게시 2026-01-02
- https://openai.com/index/openai-grove **[미열람 — 403 도메인]**

**법인·사업자등록 없이 신청 가능한가:**
- **자체 크레딧 프로그램 → 미확인.** OpenAI 소유 페이지를 한 건도 열지 못했으므로 **자격요건 원문 인용 불가. 출처 미확보.**
- **OpenAI Grove → 법인 요건 없음(원문 확인).** 공식 포럼 공고 원문: **"a program for technical talent at the very start of their company-building journey"**, **"offers pre-idea individuals deeply curious about building in AI a dense talent network"**, **"We recommend individuals from all backgrounds, disciplines, and experience levels apply."** 회사 보유나 법인 설립을 요구하는 문장은 **없다** — [OpenAI Community](https://community.openai.com/t/apply-to-openai-grove-for-early-stage-company-builders/1370781) **[직접 열람]**
  - 즉 Grove 는 **"pre-idea 개인"** 대상이므로 법인 없는 팀에게 구조적으로 열려 있던 **유일한 OpenAI 경로**였으나, 이미 마감됐다.

**제공 크레딧 규모:**
- 자체 크레딧 프로그램: **공식 금액 출처 미확보.** 서드파티들은 금액이 공개되지 않는다거나($2,500 시작 등) 서로 다르게 보고하며 **상충**한다.
- OpenAI Grove: **공고 원문에 크레딧이나 금액 언급이 전혀 없다.** 제공 내역은 **"a dense talent network, co-building with OpenAI researchers, and resources designed to accelerate your journey"** 와 일반 공개 전 모델·도구 선행 접근뿐 — [OpenAI Community](https://community.openai.com/t/apply-to-openai-grove-for-early-stage-company-builders/1370781) **[직접 열람]**
  - 서드파티가 전하는 "Grove $50K 크레딧" 은 **공식 공고 원문에 없다.** 미확인으로 분류.

**페이퍼닥 적합성:** 원문 확인 불가로 **판단 보류**. Grove 는 샌프란시스코 5주 현장 프로그램(약 15명)이라 한국 소재 3~5인 팀에는 구조적으로 부적합하며, 어차피 마감됐다.

### 상충하는 정보 (주의)

- "OpenAI 자체 스타트업 크레딧 중단" 주장: guptadeepak.com 이 **2026-09-14 확인**이라며 "OpenAI 소유 페이지에 신청 폼도 공개 크레딧 금액도 없다", "Ramp 경로와 Researcher Access 경로도 더 이상 제공되지 않는다"고 보고. fin.ai(2026-08)도 "이제 파트너 VC 네트워크 경유만 가능하고 OpenAI는 금액을 공개하지 않는다"고 보고.
- 이에 **상충**하는 소스: creditforstartups.com(2026-10-03 확인 표기)은 파트너 VC 추천 코드 경로가 살아 있고, 신청 시 추천 코드 + OpenAI org ID + 제품 설명 + 비즈니스 이메일 + 기본 펀딩 정보가 필요하다고 기술. klymentiev.com(약 1개월 전)은 Ramp 고객 최대 $2,500, Researcher Access 최대 $1,000 을 여전히 게시.
- **어느 쪽도 OpenAI 소유 페이지가 아니다.** 따라서 이 조사는 **"현존 여부 미확인"** 으로 종결한다. 다만 **모든 소스가 일치하는 점 하나**는 "공개된 셀프서비스 신청 경로는 없고, 있다면 VC 추천 경유" 라는 점이다.

### Inferences

- 서드파티 전원이 "공개 신청 경로 없음, VC 추천 전용" 에 수렴하므로, **투자 이력이 없는 페이퍼닥은 (프로그램이 존재하더라도) 자격 미달일 가능성이 높다**는 판단. 단 이는 서드파티 기반 추정이다.
- OpenAI 모델이 필요하다면 **Azure OpenAI Service 를 Microsoft for Startups 크레딧으로 쓰는 우회 경로**가 사실상 유일한 실효 경로로 보인다(Q4 참조). 이 역시 추정이다.

### Gaps

- **핵심 미해소:** OpenAI 소유 페이지의 자격요건 원문. openai.com 전체가 이 환경의 WebFetch 에 403 을 반환하고 web.archive.org 도 차단되어, **이 환경에서는 추가 우회 수단이 없다.**
- **권고:** 사람이 직접 브라우저로 https://openai.com/startups/ 와 https://openai.com/index/openai-grove 를 열어 확인해야 한다. 또는 OpenAI 영업·지원에 직접 문의.
- Ramp / Researcher Access 경로의 현재 유효 여부 — 공식 확인 불가.
- Grove 차기 회차 개설 여부 — 2026-01 이후 공고를 찾지 못함.

## Q3. Google for Startups Cloud Program — 법인 요건이 있는가? (액셀러레이터와 별개인 클라우드 크레딧 프로그램)

### Takeaway

**공식 자격 페이지가 JavaScript 전용 렌더링이라 원문을 취득하지 못했다** (cloud.google.com/startup/benefits 는 본문이 97자만 반환). 법인 요건은 **"원문에 언급 없음 — 확인 안 됨"**. 더 중요한 문제는 **Start 티어의 창업 기간 요건이 Google 자체 페이지들 사이에서 24개월 대 5년으로 서로 다르다**는 점이다.

### Cited Findings

**프로그램명:** Google for Startups Cloud Program (Start 티어 / Scale 티어)
**운영 주체:** Google Cloud
**마감:** **미확인.** 공식 본문에서 마감 또는 상시 여부를 확인하지 못함.
**출처 URL:**
- https://cloud.google.com/startup — 열었으나 제목만 반환, 본문 잘림
- https://cloud.google.com/startup/faq — 열었으나 본문 잘림
- https://cloud.google.com/startup/benefits — **열었으나 본문이 97자(제목뿐). 동적 렌더링으로 판단**
- https://cloud.google.com/startup/apply — Google 로그인으로 리디렉션
- https://cloud.google.com/startup/pre-funded — **[스니펫만]**
- web.archive.org — 이 환경에서 차단
- ※ 즉 **Google 공식 자격요건 원문은 이 조사에서 한 줄도 직접 확보하지 못했다.**

**법인·사업자등록 없이 신청 가능한가 → 원문에 언급 없음 — 확인 안 됨.**
- 공식 페이지 본문을 읽지 못했으므로 **인용 불가**. incorporation / legal entity / business registration 요건의 유무 자체가 미확인.
- 참고로 **[스니펫만]** 경로에서 확인된 제외 대상에도 "법인 미보유"는 없다: "Google cannot accept companies that have IPO'd or been acquired, educational institutions, government entities, nonprofits, or personal blogs" 외에 dev shops, 컨설팅, 에이전시, 크립토 마이닝 제외. **이는 스니펫 경유이므로 확정 근거로 쓰지 말 것.**
- 주목할 조건 **[스니펫만]**: 회사 도메인이 신청 31일 이내에 유료 Google Workspace 를 구독한 상태면 안 된다 — "The domain must not be subscribed to a paid Google Workspace plan, or subscribed within 31 days of applying". **"회사 도메인" 개념이 전제되므로 도메인 보유가 실질 요건일 가능성**이 있으나 미확인.

**제공 크레딧 규모 (모두 [스니펫만] — 공식 본문 미확인):**
- Start 티어: Google Cloud 크레딧 **$2,000**. 유효기간은 소스에 따라 **12개월**(benefits/pre-funded 페이지 스니펫) 또는 **2년**(약 1,288일 전 Google Cloud 블로그 — 구형으로 판단)으로 **상충**. 추가로 Google Skills 크레딧 $200, 신규 가입 적격 시 Google Workspace Business Plus 12개월, Google AI Studio 무료 티어.
- Scale 티어: "up to $200,000 USD, or up to $350,000 USD for Scale tier AI startups" (FAQ 스니펫). **Scale 은 "For VC-funded startups" 로 기술되어 페이퍼닥은 해당 없음.**

**창업 기간·투자 요건 — Google 자체 페이지 간 상충:**
- cloud.google.com/startup/pre-funded **[스니펫만]**: Start 는 "designed for digital-native technology startups, **founded within the last 24 months**, and not have received Google Cloud credits beyond the free trial" + working MVP + 명확한 비즈니스 모델 + 근시일 내 벤처 투자 유치 계획.
- cloud.google.com/startup/apply **[스니펫만]**: Start 는 "technology startup **not yet funded by an institutional investor, founded within the last five years**, and not yet received Google Cloud credits beyond the free trial."
- **24개월 대 5년이 Google 소유 페이지 두 곳에서 다르게 나타난다.** 어느 쪽이 최신인지 확정 불가.

**페이퍼닥 적합성:** Start 티어는 "기관투자 미유치 기업" 대상이라 **투자 이력이 없다는 점은 오히려 적합**하고, "working MVP + 벤처 투자 유치 계획"은 페이퍼닥 상황과 부합할 가능성이 있다. 단 $2,000 은 인프라 크레딧이며 **Claude/OpenAI API 비용에는 쓸 수 없다**(Vertex AI 경유 Gemini·Claude 사용은 별개 검토 필요). 액셀러레이터 쪽은 선행 조사에서 투자 요건으로 이미 탈락 확인됨.

### Inferences

- Start 티어가 명시적으로 "기관투자 미유치(pre-funded)" 기업을 겨냥한다는 점에서, 투자 없는 초기 팀을 배제하지 않는 설계로 **보인다**. 그러나 "startup/company" 를 전제하므로 법인 없는 팀의 가능 여부는 별개 문제이며 **미확인**이다.
- Google Cloud 전 페이지가 동적 렌더링이어서 자동 수집으로는 확인이 어렵다. **사람이 브라우저로 직접 확인해야 한다**는 판단.

### Gaps

- **법인 요건 유무 자체** — 공식 원문 미취득.
- Start 티어 창업 기간 요건이 24개월인지 5년인지 — Google 자체 페이지 간 상충, 미해결.
- 마감/상시 여부 — 미확인.
- 크레딧 유효기간(12개월 대 2년) — 상충, 미해결.
- **권고:** 사람이 https://cloud.google.com/startup/benefits 와 /startup/apply, /startup/pre-funded 를 브라우저로 열어 자격 불릿을 확인할 필요.

## Q4. Microsoft for Startups Founders Hub — 법인 없이 신청 가능한가? Azure OpenAI 크레딧 규모는?

### Takeaway

공식 문서(learn.microsoft.com, 2026-10-09 갱신)의 자격 항목에 **법인·사업자등록은 없다** — 단계(Pre-seed~Series B), B2B 소프트웨어/AI, 독립 법인체(비자회사), 운영 지역만 요구한다. 그러나 **크레딧 확대 단계에서 "business verification"(사업자 인증)을 요구**하며 그 정의가 공식 문서에 없어, **법인·사업자등록 없이 끝까지 갈 수 있는지는 확인 안 됨**이다. 투자 유치는 **명시적으로 불필요**(FAQ 원문 확인).

### Cited Findings

**프로그램명:** Microsoft for Startups (Founders Hub)
**운영 주체:** Microsoft
**마감:** **상시로 보임.** 마감·코호트 언급 없고 신청 후 약 3영업일 내 심사. (※ "상시"가 원문에 명시된 것은 아니며 마감 언급이 없다는 뜻)
**출처 URL (모두 [직접 열람]):**
- https://learn.microsoft.com/en-us/startups/microsoft-for-startups/application (갱신 2026-10-09)
- https://learn.microsoft.com/en-us/startups/microsoft-for-startups/mfs-faqs
- https://learn.microsoft.com/en-us/startups/benefits

**법인·사업자등록 없이 신청 가능한가 → 자격 항목에 법인 요건 없음. 단 "business verification" 때문에 최종 확인 안 됨.**
- 공식 자격 항목 원문 (법인·사업자등록 항목 자체가 없음):
  - "Stage: Pre-seed through Series B funding"
  - "Business model: B2B startups building software, AI, or technology solutions"
  - "Privately held: Independent companies (not subsidiaries of larger organizations)"
  - "Compliance: Headquartered in a region where Microsoft for Startups operates"
- 그러나 신청 전 준비물에 **"Registered startup name (must match your legal documents)"** 와 "Website (if available)" 가 있다 — **"legal documents" 와 일치하는 등록 상호**를 요구하므로 사업자등록이 실질 전제일 가능성.
- 투자자 코드 경로의 사업자 정보 입력 안내 원문: "The registered startup name and address must match legal documents for your business. Mistakes or mismatches can cause business verification to fail…"
- 코드 없는 경로는 사업자 정보 양식을 거치지 않는다: "Without an investor code, you go directly to Azure account creation rather than completing the longer application form."
- **그러나 FAQ 는 크레딧 확대에 사업자 인증을 요구한다: "$1,000 for 90 days, then an additional $4,000 for 180 days after business verification"** — business verification 이 법인등기부·사업자등록증을 요구하는지는 **공식 문서에 정의 없음. 미확인.**
- → 결론: **초기 소액 크레딧은 법인 없이 받을 여지가 있으나, 확대 단계에서 막힐 가능성이 있다. 확인 안 됨.**

**제공 크레딧 규모 (공식 페이지 기준이나 페이지 간 수치 상충):**
- 코드 없는 경로: 신청 페이지에 **시작 $200**, 이후 **"up to $150,000"** 까지 확대 가능.
- 코드 있는 경로: 신청 페이지에 **$1,000**, 승인 후 **"up to $150,000"**. FAQ 는 투자자 코드 승인 시 "most startups begin with $100,000" 이라고 기술.
- FAQ(투자자 없는 경우): **"$1,000 for 90 days, then an additional $4,000 for 180 days after business verification"**
- → **같은 사이트 내에서 $200 과 $1,000 이 상충**한다. 페이지 갱신 시점 차이로 보이며 **최신값 미확정.**
- Benefits 페이지: "Up to $150K in Startup credits over time as your startup demonstrates verified progress, service adoption, and sustained Azure usage. Eligible Investor Network-backed startups may unlock up to $200K"
- **Azure OpenAI 전용 크레딧 금액 → 공식 출처 미확보.** Benefits 페이지는 "Access to Azure AI capabilities, including models available through Microsoft Foundry" 라고만 하고 별도 금액을 주지 않는다. **Azure 크레딧을 Azure OpenAI 에 쓰는 구조로 보이나, 전용 크레딧 금액은 미확인.**

**투자 요건:** **없음(원문 확인).** FAQ: **"I'm not working with an investor. Can I still get credits? Yes."** 투자자 코드는 상위 등급 해금용.

**페이퍼닥 적합성:** B2B 소프트웨어/AI 라는 조건에 **정확히 부합**하고 투자 요건이 없어 현실적으로 가장 접근성 높은 글로벌 프로그램. Azure 크레딧으로 **Azure OpenAI 경유 GPT 사용이 가능**하므로, OpenAI 자체 프로그램이 막힌 상황에서 **OpenAI 모델 접근의 사실상 유일한 보조 경로**. 다만 Claude API 에는 쓸 수 없다(Anthropic 크레딧은 1st-party 전용이고, 역으로 Azure 크레딧은 Anthropic 직접 API 에 사용 불가).

### Gaps

- **"business verification" 의 구체 요구 서류** — 법인등기부·사업자등록증 필요 여부. 공식 문서에 정의 없음. **이것이 페이퍼닥의 당락을 가르는 핵심 미확인 항목.**
- $200 / $1,000 / $4,000 중 현행 수치 — 공식 페이지 간 상충.
- Azure OpenAI 전용 크레딧 금액 — 공식 출처 미확보.
- "Headquartered in a region where Microsoft for Startups operates" 에 한국이 포함되는지 — 미확인.

## Q5. AWS Activate — Founders 티어는 투자유치·법인 없이 가능한가? 제공 크레딧은?

### Takeaway

Founders 티어는 **투자 유치가 명시적으로 불필요**하고("bootstrapped or self-funded"), 자격 요건에 법인·사업자등록·웹사이트가 **열거되어 있지 않다**. 그러나 **FAQ 본문을 취득하지 못해** 법인 요건은 **"원문에 언급 없음 — 확인 안 됨"** 이다. 크레딧은 **$1,000 시작, 최대 $5,000**.

### Cited Findings

**프로그램명:** AWS Activate — Founders 티어
**운영 주체:** Amazon Web Services
**마감:** 열람 페이지에 마감 언급 없음. **상시로 보이나 원문 명시 없어 단정하지 않음.**
**출처 URL:**
- https://aws.amazon.com/startups/credits **[직접 열람]**
- https://aws.amazon.com/startups/credits/faqs — startups.aws.com 으로 리디렉션 후 **404**, 본문 미취득

**법인·사업자등록 없이 신청 가능한가 → 원문에 언급 없음 — 확인 안 됨.**
- 열람한 페이지의 자격 문구에 법인·사업자등록·웹사이트 요건은 **없다**. 확인된 문구는 다음뿐:
  - "Apply directly if you're bootstrapped or self-funded"
  - 공통 요건: **"Pre-series B, founded in the last 10 years, AWS Account on Paid Tier Plan"** (이전 Activate 크레딧 수령 관련 조건이 추가로 붙는다고 기재)
- **AWS 계정(유료 티어 플랜)은 필수.** 이는 원문 확인.
- FAQ 본문을 못 읽어 숨은 법인 요건 유무를 배제할 수 없다.

**제공 크레딧 규모 (원문 확인):** **"Up to $5,000 USD in Activate Credits"** / **"Start with $1,000 USD in Activate Credits. Select participants may qualify for additional credits up to $5,000"**

**투자 요건:** **없음(원문 확인).** Founders 티어는 자기자금(self-funded)·부트스트랩 대상.

**페이퍼닥 적합성:** 투자 요건이 없고 창업 10년 이내라 요건상 가장 느슨하다. 다만 **AWS 인프라 크레딧이므로 Anthropic/OpenAI 직접 API 비용에는 쓸 수 없다.** AWS Bedrock 경유로 Claude 를 쓰면 Activate 크레딧이 적용될 가능성이 있으나(Bedrock 은 AWS 서비스), **이 조사에서 검증하지 않았다 — 별도 확인 필요.** 참고로 Anthropic 측 크레딧은 역방향으로 Bedrock 에 사용 불가임이 확인됐다.

### Gaps

- FAQ 본문(법인·사업자등록·웹사이트 요건) — 페이지 404 로 미취득.
- 마감/상시 여부 — 원문 명시 없음.
- **Activate 크레딧이 AWS Bedrock 경유 Claude 호출에 적용되는지** — 미확인. 적용된다면 페이퍼닥에게 Anthropic 프로그램 마감의 **실질 대안**이 되므로 **우선 확인 권고**.

**운영 주체:** NVIDIA
**마감:** **상시 — 원문 확인.** "There are no application fees, deadlines, or cohorts." 연중 신청 가능.
**출처 URL:** https://www.nvidia.com/en-us/startups/ **[직접 열람]**

## Q9. 국내 LLM 크레딧 — 과기정통부·NIPA 「초거대 AI 활용 지원」류 사업이 열려 있는가?

### Takeaway

**현재 공고 중인 「초거대 AI 활용/확산 지원」류 사업을 찾지 못했다.** nipa.kr 사업공고 목록 1페이지(총 36페이지)에서 AI 바우처·클라우드·GPU·초거대 AI 관련 공고는 모두 종료되었거나 없었다. 진행 중인 AI 관련 공고는 페이퍼닥과 무관한 한-두바이 AI 사이버보안 포럼 운영 용역 모집(2026-10-15 ~ 11-04) 하나였다.
