# D. 경쟁·제품 검수 — 「가맹 정보공개서·계약서 점검」

- 검수일: 2026-11-09
- 검수자 관점: B2B/B2C SaaS 제품 책임자 겸 경쟁 분석가
- 확인 방법: 네이버 검색(브라우저 안에서 쿼리 약 35개 직접 조회), 공정위 가맹사업거래 누리집 직접 열람, 공공데이터포털 목록 조회, 경쟁 서비스 누리집 직접 열기(curl), 애플 앱스토어 검색 API

## 0. 한 줄 결론

**이전 조사의 「창업자 쪽 점검 도구 없음」은 틀렸다.** 가맹거래사가 직접 만든 **「안심프차」(가칭)**가 같은 기능(가맹계약서 PDF를 올리면 위약금·영업지역·갱신 조항 진단, 공정위 12,000개 브랜드 데이터 검색, 가맹사업법 챗봇)을 **무료**로 2026년 10월에 공개했다. 이 운영자는 **"변호사법 때문에 AI 계약 진단은 돈을 받으면 안 된다"**고 판단하고 영구 무료로 정했다. 일반 계약서 AI(CLAUSEAI, 1건 1,100원)와 무료 브랜드 비교 서비스(마이프차·점포가이드·가맹희망플러스)도 이미 있다. 2028년부터는 공정위가 정보공개서 앞머리에 「핵심정보 요약본」을 의무로 넣게 한다.

**총점 50/100 → 판정: 중단**(지금 형태 기준. 바꿔 볼 만한 방향은 7장).

## 3. MVP 검토

| 항목 | 확인 내용 |
|---|---|
| 정보공개서 양식 | 시행령에 기재사항이 정해져 있고 공정위 **「정보공개서 표준양식」 고시**가 있다(2026-02 개정 행정예고, 2028-01-01 새 양식 시행). 항목 순서가 정해져 있어 구조 파악이 쉽다. 단, 2028년에 목차가 바뀌어 **파서를 두 벌** 유지해야 한다 |
| 공정위 공개본 | 누리집 열람 화면이 **HTML 표 16개**(재무, 가맹점 변동, 평균 매출, 광고비, 가맹금 예치, 법 위반 등)라서 긁어 오기 쉽다. 직접 열어 확인함 |
| OpenAPI | 공공데이터포털에 공정위 가맹 API **41건**(정보공개서 목록, 본부 일반정보, 부담금, 특수관계인 등), 경기도 연계 데이터(가맹점 변동 등) 있음 |
| 창업자가 받는 원본 | PDF(전자문서 제공 허용) 또는 종이. 종이·스캔본이면 문자 인식(OCR) 필요. 본부마다 표 모양이 달라 「예상매출 산정서」·인테리어 내역은 파싱 난이도 중상 |
| 가맹계약서 | 공정위 **표준가맹계약서**(업종별)가 있어 「표준과 다른 조항」 비교 규칙을 만들기 좋다 |
| 1인 개발 기간 | 공정위 데이터 수집과 대조 2주, PDF 파싱·규칙 30~40개 2~3주, LLM 설명·화면 1~2주 → **5~7주**. 안심프차가 1인 개발로 이미 해냈다는 점이 쉬움과 해자 없음을 같이 보여 준다 |
| 해자 | **약함.** 데이터는 공공(8,279명 활용신청), 규칙은 법조문·표준계약서라 누구나 베낄 수 있다. 가맹거래사 자격과 사람 자문 연계가 유일한 해자인데, 그 자리를 안심프차가 먼저 잡았다 |

## 4. 시장 숫자 (확인한 것만)

- 2025년 말 가맹본부 9,960개, 브랜드 13,725개, 가맹점 **37만 9,739개**(공정위 2025 가맹사업 현황 통계, 2026-04-12 보도. 메가경제·프라임경제 기사로 확인)
- 외식업 개점률 18.2%, 폐점률 15.8%. 서비스업 19.2%와 9.3%, 도소매 9.5%와 8.6%
- → 해마다 새로 여는 가맹점은 **대략 5~7만 개로 추정**(개점률×점포 수로 어림잡음, 명의변경 제외). 계약 전에 정보공개서를 받아 보는 사람은 그 몇 배
- 지불의사 기준점: 사람 자문 **15만원 안팎** + 숙고기간 7일 단축이라는 법적 이득. AI 범용 진단 **1,100원**. 같은 기능 AI **0원**(안심프차)

## 6. 핵심 위험 3가지

1. **직접 경쟁자가 같은 기능을 무료로 이미 출시했다.** 안심프차는 가맹거래사가 만들어 신뢰가 있고 사람 자문으로 이어지는 길도 갖췄다. 1인 개발자가 늦게 들어가 이길 근거가 없다.
2. **변호사법 제109조가 유료화를 막는다.** 경쟁자가 이 법을 근거로 무료를 택했다는 사실 자체가 위험 신호다. CLAUSEAI는 1,100원을 받으면서 「법률사무를 하지 않는다」는 문구로 버티고 있다. 이 방식이 안전한지는 판례에 달려 있다(비전문).
3. **제도가 문제를 직접 푼다.** 2028년부터 정보공개서 요약본, 가맹점 안정성 지표, 분기별 점포 수 갱신이 의무가 된다. 여기에 원래 무료인 가맹희망플러스까지 있어 「읽기 어려움」이라는 고통이 줄어든다.

## 7. 그래도 하려면 (조건부로 바꿀 수 있는 방향)

- **가맹거래사·변호사용 B2B 검토 보조 도구:** 자문확인서 업무(건당 15만원 안팎)에서 대조표와 질문 목록을 자동으로 만들어 주는 도구로 팔면, 사람이 최종 책임을 지므로 변호사법 위험이 줄어든다. 다만 안심프차가 가맹거래사 쪽에서 같은 방향을 갈 수 있다. 전국 가맹거래사 수가 많지 않아 시장 상한도 작다(비전문).
- **창업대출·보증 기관 B2B:** 신용보증재단·은행이 대출 심사 때 쓰는 「브랜드 위험 지표」(폐점률·재무·법 위반 사실·차액가맹금)를 사실 데이터로만 제공한다. 법률 판단이 빠지므로 위험이 낮다. 이번에 은행 쪽 기존 상품은 찾지 못했지만, 영업 주기가 길다.
- 둘 다 이 아이템의 원래 가설(창업자가 직접 쓴다)과 다르므로, 별도 아이템으로 다시 채점해야 한다.
