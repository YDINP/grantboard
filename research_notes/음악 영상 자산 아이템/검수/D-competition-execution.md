## 5. 시너지와 묶는 순서

```
A 추모 영상 ──(배경 음악)──> 오케스트라 편곡 파이프라인 (권리 깨끗한 자체 음악)
   │                               │
   └─(같은 주문·상담 양식, 같은 스마트스토어·크몽 계정, 리뷰)──> D 로고송·사운드 로고
                                     │
                         (사운드 로고를 코드 합성으로) ──> B 합성 엔진 재활용
C 보카로 도구 ── YDIN 채널 진열대 ── (다른 후보와 고객이 겹치지 않음)
```

- **A ↔ 음악:** 추모 영상의 배경 음악을 Suno가 아니라 오케스트라 파이프라인으로 만들면, 음원 권리 문제를 피하고 경쟁자(대부분 무료 BGM·AI 음원)와 다른 점이 하나 생긴다.
- **A → 확장:** 반려동물에서 반응이 약하면 같은 제작 순서로 **부모님 추억 영상**(크몽 리뷰 수십~수백 건 시장)으로 옮긴다. 이쪽이 실제 수요의 중심이다.
- **D ↔ B:** D의 유일한 진짜 차별인 "코드로 합성한 사운드 로고(저작권 양도 가능)"가 KeyClack 엔진에서 나온다. B를 앱으로 팔기보다 **D의 상위 옵션 재료**로 쓰는 편이 돈이 된다.
- **C:** 다른 후보와 고객이 겹치지 않는다. 테토 판본 확인이 먼저이고, 상품보다 **크몽 1:1 레슨**(돈이 오가는 것이 확인된 형태)이 맞다.

**순서:** 1개월 A → 2개월 A 유지 + D(사운드 로고 옵션 포함) 등록 → 3개월 판정. B는 무료 공개로 포트폴리오·블로그 소재로만 쓰고, C는 테토 판본 확인 뒤 레슨 형태로 다시 검토한다.

**공통 선행 조건:** 회사 취업규칙의 겸업 조항 확인(1일차). 확인 전에는 사업자 등록과 판매 등록을 하지 않는다.
