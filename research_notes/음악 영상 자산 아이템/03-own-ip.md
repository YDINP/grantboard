**핵심 해석**
1. "Suno 음원 그 자체"를 파는 길(스톡 음원·밴드캠프·BGM 채널 광고)은 2026년에 대부분 닫혔거나 좁아졌다.
2. 반대로 **생성형 AI가 아닌 것**(코드로 합성한 타건음, 사용자가 직접 만든 도구·지식)은 이 규제를 통째로 피한다. 내 자산 중 이 성격이 강한 게 합성 타건음 엔진과 SynthV 조교 파이프라인이다.
3. 테토 쪽 위험은 생각보다 작다. 단, **제품판 보유가 전제**다. 라이트판이면 YDIN 수익화 전체가 막힌다 → 1순위로 확인할 것.

## 1. 후보 10개

### 후보 A. 보카로 제작 도구·조교 템플릿·실전 가이드 판매
- **무엇을**: synthv-kit 일부(Suno 곡 → 테토 .svp 변환 단계별 스크립트, 박 보정·채보 도구), 창법 프리셋 .svp 템플릿(しゃくり·フォール·비브라토 묶음), 한국어/일본어 「Suno 곡을 테토로 다시 부르게 하기」 실전 가이드 PDF·영상
- **어디서**: BOOTH(일본 보카로P 시장), 크몽·리틀리(국내 전자책), Gumroad(영어권)
- **수익 사례(작은 판매자)**: 국내 전자책 "19권 끝에 첫 1만원 주문" [2차, 2026-09-29 블로그]. 노션 템플릿 묶음은 2~10만원대에 판매 중 [2차 네이버 쇼핑]. 보카로 도구 BOOTH 판매액 공개 사례는 못 찾음
- **내 자산 우위**: Suno→SynthV 전 과정 자동화 + 실제 조교 경험(v26 음정, 창법 흉내, 2.2.1 버그 우회 등)은 한국어 자료가 거의 없고 일본어 자료도 수작업 위주. "AI 곡을 사람 손으로 다듬는 법"은 KOMCA·유튜브가 요구하는 '사람 주도'와도 맞는 주제
- **정책 위험**: 낮음~중간. 테토 음원 라이브러리 자체나 AI 학습물 배포는 금지 [1차] → 도구·.svp(노트·파라미터 데이터)만 팔고 음성 파일은 넣지 않으면 됨. .svp 배포가 허용되는지는 Dreamtonics 약관 추가 확인 필요「추정: 노트 데이터라 문제없을 가능성 큼」. Suno 출력 샘플을 상품에 넣지 말 것
- **첫 매출까지**: 3~6주 (가이드 1권 + 템플릿 1종)

### 후보 B. KeyClack 데스크톱 타건음 앱 유료 판매
- **무엇을**: 전역 키 훅 + 합성 타건음 앱(이미 Phase 3, 합성 팩 3종) 유료판 또는 무료 + 소리 팩 추가 구매
- **어디서**: Microsoft Store, Steam(소프트웨어 분류), Gumroad/itch.io, 국내는 자체 페이지
- **수익 사례**: 맥용 Klack은 1인 개발자 앱, 일회 결제 $3.99→$4.99, 9to5Mac·Creative Bloq 등에 소개되며 퍼짐 [2차]. 판매량은 비공개. 국내 경쟁: 알툴즈 알토독(타건음 9종 조합), 한컴타자 타건음 상점, 모바일 키캡 ASMR 앱 KeyKey·키클랙 [2차 네이버]
- **내 자산 우위**: **녹음 샘플이 아니라 코드 합성**이라 저작권·AI 정책 걱정이 없고, 스위치·윤활·하우징을 숫자로 바꿔 소리를 무한히 만들 수 있음(녹음 기반 경쟁작은 키보드 수만큼 녹음해야 함). Windows 쪽엔 Klack급 완성도 앱이 드묾「추정」
- **정책 위험**: 낮음. 게임이 아니라 유틸리티라 회사 업무와 안 겹침. 전역 키 훅은 백신 오탐 가능 → 코드 서명 필요(연 수십만 원)
- **첫 매출까지**: 1~2개월 (설치본·스토어 등록)

### 후보 C. 합성 타건음·UI 효과음 팩 판매
- **무엇을**: 키보드·타자기·버튼·UI 클릭 효과음 묶음(WAV), 영상 편집자·스트리머·앱 개발자용

- **정책 위험**: 낮음~중간. 구매자 중 게임 개발자가 많음 → 게임 외주는 아니지만 회사 겸업 규정에서 "게임 관련 판매" 해석 확인 권장
- **첫 매출까지**: 2~4주

## 3. 상위 3개 추천

### 1위 A. 보카로 제작 도구·조교 템플릿·실전 가이드 판매 (75점)
- **이유**: 경쟁자가 같은 AI를 쓰는 시장에서 내 우위는 "AI 결과물"이 아니라 "AI 곡을 사람 손으로 다듬는 과정"이다. 이 과정을 파는 건 유튜브·KOMCA·유통사가 2026년에 요구하는 방향(사람 주도)과 같은 쪽이라 정책 바람을 맞지 않는다. 테토 규약은 음원 재배포·학습물 배포만 막고 도구·지식 판매는 막지 않는다 [1차].
- **첫 행동**: ①테토 제품판 보유 확인 ②「Suno 곡 → 테토 조교」 한국어 가이드 1권 + 창법 프리셋 .svp 1종 → 크몽·리틀리, 일본어판 → BOOTH ③YDIN 영상 설명란을 판매 페이지로 연결(D와 묶어 채널을 진열대로 씀)
- **직장인 부업 적합도**: 높음. 한 번 만들면 끝, 고객 응대가 거의 없다.

### 2위 B. KeyClack 데스크톱 타건음 앱 (72점)
- **이유**: 코드 합성이라 AI·저작권 정책 위험이 사실상 없는 유일한 후보. 맥에는 1인 개발 유료 앱 선례(Klack $4.99)가 있고 Windows 쪽은 비어 있다「추정」. 앱은 게임이 아니어서 회사 업무와도 안 겹친다.

- **직장인 부업 적합도**: 중간~높음. 초기 2달 집중 개발이 필요하지만 이후 손이 덜 간다. 업데이트·오류 대응은 남는다.
